# 屏幕常亮

一个轻量的 macOS 菜单栏工具，用来保持屏幕常亮，避免系统自动息屏。

[下载最新版](https://github.com/FanMiLi666/screen-awake/releases/latest)

## 功能

- 保持屏幕常亮
- 菜单栏后台运行
- 体积小，无复杂配置

## 应用信息

- 名称：屏幕常亮
- 版本：2.0
- 系统要求：macOS 11.0+
- 架构：Apple Silicon arm64

## 使用方式

1. 从 [Releases](https://github.com/FanMiLi666/screen-awake/releases/latest) 下载 zip。
2. 将 `屏幕常亮.app` 拖到 `Applications` 文件夹。
3. 双击打开应用。

## 说明

当前仓库保存的是已打包的 `.app` 应用包，不包含完整源码工程。
