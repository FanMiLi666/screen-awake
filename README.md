# 屏幕常亮

一个轻量的 macOS 菜单栏工具，用来保持屏幕常亮，避免系统自动息屏。

[下载最新版](https://github.com/FanMiLi666/screen-awake/releases/latest)

## 功能

- 一键保持 Mac 屏幕常亮，减少系统自动息屏、锁屏对工作的打断。
- 通过 macOS 自带的 `caffeinate` 能力实现，不需要额外安装后台服务。
- 菜单栏常驻运行，不占用 Dock 栏位置，适合长期放在后台。
- 点击菜单栏图标即可切换常亮状态，适合临时会议、下载、演示和长时间阅读。
- 体积小、启动快，没有复杂配置项。

## 适用场景

- 投屏或演示时不希望屏幕突然熄灭。
- 长时间下载、同步、跑脚本时希望 Mac 保持活跃。
- 阅读文档、看教程、查看仪表盘时不想频繁唤醒屏幕。
- 临时需要屏幕常亮，但不想修改系统电池或锁屏设置。

## 应用信息

- 名称：屏幕常亮
- 版本：2.0
- 系统要求：macOS 11.0+
- 架构：Apple Silicon arm64

## 使用方式

1. 从 [Releases](https://github.com/FanMiLi666/screen-awake/releases/latest) 下载 zip。
2. 将 `屏幕常亮.app` 拖到 `Applications` 文件夹。
3. 双击打开应用。
